### Ticket Categories
- **DATABASE**: Database connections, query timeouts, storage capacity, connection pools, or data replication issues.
- **NETWORK**: Connectivity loss, DNS resolution failures, firewall blocks, latency, or VPN issues.
- **AUTHENTICATION**: SSO, OAuth, permission denied, expired credentials, or access control failures.
- **INFRASTRUCTURE**: Server availability, VM/container crashes, high CPU/RAM usage, disk full, or cloud host failures.
- **SOFTWARE**: Application bugs, runtime exceptions (e.g. 500 internal server errors), UI bugs, or broken API endpoints.
- **OTHER**: General inquiries, documentation requests, or unclassified issues.
